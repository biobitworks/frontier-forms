Trained components vs the untrained baseline

Baseline: Apple Vision OCR plus a rule parser, with no learned parameters. Each arm changes only the trained part, and the OCR engine stays the same. The unit is one image; there are 46 test images (23 patients, each rendered clean and as a scan). Success means all 7 fields equal the printed value.

2⁴ factorial · same model weights throughout

Which admission checks catch planted errors?

There are 108 planted field errors across 135 forms. Each check either admits or rejects an extracted field. Detection is the share of planted errors rejected. False admissions are wrong values that got through. The commitment check compares each value with a salted hash of its source, so it catches any changed value by design. The finding is how much the other checks miss. These bars are descriptive counts. The paired test in the ledger below uses per-image success: at least one field admitted and no wrong value admitted. That rises from 50/135 with no checks to 135/135 with the commitment check.

Per-epoch Merkle ledger

Detector training, one committed leaf per epoch

The YOLOv8n field detector was fine-tuned on the training split only. After every epoch it was scored on the dev split and compared with the previous epoch using a paired exact McNemar test. The epoch was then committed as a hash-chained leaf marked GAIN, LOSS or NEUTRAL. The second run drops the scan variants (leave one mechanism out).

What was standard and what project-specific work added

Standard, used as-is

  • YOLOv8n fine-tuning with Ultralytics defaults
  • Apple Vision OCR, untrained
  • Pretrained Qwen models through Ollama, inference only
  • A post-OCR correction table built by counting
  • Exact McNemar, paired bootstrap, Holm correction

Added within the recorded project experiments

  • Every training epoch committed as a hash-chained leaf with its weights hash and a paired test against the previous epoch
  • A preregistered trained-versus-untrained comparison, fit on train only and scored on test once
  • Per-field salted source commitments used as an admission gate, measured in a full 2⁴ factorial with leave-one-mechanism-out
  • A planted-error dataset with opaque image ids and a private list of what was planted
  • Weights, mechanism and outcome recorded separately for every comparison
