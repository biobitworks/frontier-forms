# Rendered synthetic form images with gold DOM boxes

57 PNG renders (3 blank templates + 54 filled held-out test forms) of the three Frontier Forms templates, filled from MITRE Synthea patients. GOLD_BOXES.json holds the browser DOM box of every field. Input to V1 qwen2.5vl, T1 Tesseract and the box validators.

Source: PR #10 #19. All patients are synthetic (MITRE Synthea). Index of every figure and image set: `docs/figures/FIGURES.md`.
