# FF-SYNTHEA-FORMS-COHORT-V1

100 living synthetic patients from MITRE Synthea v3.4.0 (Apache-2.0), seed 20261102, reference date 2026-11-01. All names, addresses, phone numbers and SSN-format identifiers are generated by Synthea and are synthetic. Committed with Byron's approval (2026-11-02).

- `GENERATION.json`: pinned generator, exact command, determinism check, selection and split rule.
- `MANIFEST.json`: per patient raw SHA-256, subset SHA-256, split, and both cohort Merkle roots.
- `bundles/`: forms-subset-v1 FHIR R4 bundles (`scripts/build_forms_subset.py`). Only the resources the form lane reads are kept; B0 and oracle outputs are identical on raw and subset bundles.

Splits (split-v1, by patient id hash): train 63, validation 19, test 18.

This is not the teammate Supabase cohort (unpinned `synthea-sample-data-fhir-latest`, count unverified) and not Epic sandbox patients.
