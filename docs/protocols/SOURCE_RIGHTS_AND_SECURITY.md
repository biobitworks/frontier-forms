# Rights and secure export controls

Synthea: synthetic patients, not proof of clinical realism. Never use actual PHI in public repo, cloud inference or demo. Original local CSV archive retained off GitHub.

LongevityBench: Hugging Face source metadata declares CC BY-NC 4.0; raw parquet and exact answer oracle stay out of Git. The public review package has only hash descriptors, aggregate confusion metrics and 38 source-hashed paired correctness flags.

Insilico Qwen3-0.6B-Longevity: model repository lists CC BY-ND 4.0; frozen local checkpoint is not distributed, modified or used to imply commercialization rights.

Megatron-LM: Apache-2.0 source reference, pinned SHA; CUDA training NOT_TESTED. Apple Silicon MPS is not NVIDIA CUDA.

Epic technical specification is NOT an OCR dataset or authorization to write to EHR. SMART OAuth and production EHR read/write NOT_TESTED. Work in synthetic sandbox only, never on real patients without approval.

Fireworks account credentials may be absent; do not claim serverless requests executed without a provider receipt. Microsoft Document Intelligence and NVIDIA NeMo extraction are proposed separate service arms.

Snyk Code, Open Source, Container and IaC scans are independent product gates. Authenticated test outcome cannot be inferred from a CLI being installed.

Existing frozen manifest public_export=NOT_AUTHORIZED applies to the underlying raw source. Public metadata review does not change that source status.
