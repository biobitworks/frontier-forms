Methods and limits

Each arm uses the same synthetic patient cases and source bytes. Four independent source-bound correction modules challenge alphanumeric name suffixes, OCR confusables, postal-code truncation, and wrong-patient field binding. Clean controls ensure no false alteration. Tests use 2,000 patient-cluster bootstrap resamples and exact two-sided McNemar for each single-challenge stratum.

All values shown are from the versioned JSON report, whose source and challenge roots are displayed above. Formal Lean 4 invariants verify Boolean fixture semantics and fail-closed admission—not the external truth of an LLM response or SHA-256 cryptography.
